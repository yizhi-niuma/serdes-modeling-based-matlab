# 项目需求 / Requirements

本文件记录项目级的通用约定与要求，供所有验证脚本遵循。

## 验证产物约定

- **每次验证脚本执行完成后，必须在其对应的 `result/` 文件夹下新增一份对该验证脚本
  关键实现的简述文档**（纯文本或 Markdown 均可，例如
  `impl_convergence_notes.txt` / `impl_notes.md`）。该简述应至少覆盖：
  1. 验证目标与整体结构（被测对象、环路/模块、验证判据）；
  2. 关键实现要点与设计取舍（算法、初值、步长/增益、训练/收敛策略等）；
  3. 本次运行配置（关键参数、样本规模、缓存/码型来源）；
  4. 关键结果与结论（是否通过、收敛情况、已知边界或遗留问题）；
  5. 复现方法（无参默认如何运行、如何切换到长样本/其他配置）。
- 简述随结果一同提交版本库（结果大二进制如 `.mat`/大图/缓存不入库，仅入库文本简述）。
- 当实现有实质改动或结论变化时，以追加"日期 + 小节"的方式更新该简述，保留历史结论。

# SerDes Modeling

End-to-end behavioral SerDes modeling project.

## Repository Layout

- `src/`: reusable SerDes model implementation
- `validation/`: waveform, histogram, eye-diagram, and exploratory validation scripts
- `tests/`: automated regression tests with machine-checkable pass/fail criteria
- `data/`: fixed simulation inputs and reference data
- `results/`: reproducible generated outputs
- `docs/`: architecture, assumptions, decisions, status, and validation records
